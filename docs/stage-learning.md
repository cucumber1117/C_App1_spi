# ステージ学習の統合（2026-10-01）

## 変更前と変更後

通常アプリの分野別MAPと問題生成は接続されていましたが、ゲームのような番号付き進行とは別の構造でした。今回、既存のステージUIのデザインを再利用し、通常の `/` に本番の非言語問題生成を接続しました。サンプル問題・確認専用ページは復活させていません。

ホーム → ステージ選択 → 10問 → リザルト → 次のステージ、という流れです。非言語10ステージとCHECK 2つを用意しました。完走で解放し、得点では進行を止めません。

## 主な変更ファイルと理由

- `src/features/stages/catalog.ts`: 出題範囲・タイプ・難易度・配分を画面から分離。既存 `problemGenerator.ts` から10問生成。セット内の重複は除外し、直近40問も可能な範囲で回避。
- `src/features/stages/learning.ts`: 回答、完走、解放、最高評価、復習、複数の途中セットを一元管理。最終回答と解放を同じ保存単位にする。
- `src/features/stages/storage.ts`: 生成済み問題・選択肢順・回答・位置・解説状態・メモを保存。破損データは自動上書きせず、退避して再開始できる。
- `src/features/stages/ink.ts`: 手書きデータと検証。
- `src/pages/stages/StageMap.tsx`, `CategoryMap.tsx`, `stages.css`: 番号付きMAP、通常5つ＋CHECK、未解放の◇、過去の折りたたみ、NEW表示を接続。
- `src/pages/stages/StageExercise.tsx`, `exercise.css`, `InkMemo.tsx`, `ink.css`: 回答確定、画面下の解説、手書きメモ、結果と振り返りを本番の10問セットに接続。
- `src/App.tsx`, `src/pages/home/home.tsx`, `src/App.css`: ホーム・続きから・MAP・復習の導線と保存失敗時の再試行。
- `src/features/answers/checkAnswer.ts`: ステージの回答履歴に出所を付け、旧方式の誤答復習と混ざることを防止。
- `tests/stageLearning.test.mjs`: 進行・得点境界・生成・復習・保存復元・破損への回帰テスト。
- 旧 `src/features/problems/categoryMap.ts` と対応テスト、未使用 `src/features/memo/HandwritingMemo.tsx` は削除。手書き機能は接続済みの `InkMemo.tsx` を使用。

`src/pages/question/question.tsx` の先行する10問対応は維持。現在この画面は旧履歴の復習用として残しています。既存の問題生成・成績集計・旧回答履歴は維持します。

## 暫定ルール

- 通常は基礎3・標準5・応用2。CHECKは直前5ステージから2問ずつ、合計でも3・5・2。
- 01割合、02損益算、03速度算、04集合、05場合の数＋確率、06確率、07推論、08表、09割合＋損益算＋速度算、10集合＋場合の数＋確率＋推論＋表。通常画面には単元名を表示しません。
- 05は有限な出題パターンだけで重複なく10問を作れるよう、確率も含めました。正式な学習順と配分の確定は今後必要です。
- 0〜5点はプレイ済み、6〜9点CLEAR、10点PERFECT。通常再挑戦は最高評価を保持。
- 6点以下で自動復習追加、7〜9点は任意追加。重複登録しない。
- 復習は登録時の条件を保存して新しい10問を生成。7点以上で解除。通常再挑戦では復習解除しない。おすすめは古い登録順。
- 途中セットはステージ×通常/復習単位に保持し、「続きから」は最後の未完セットを優先。

## 動作確認

1. `npm run dev` で起動し、表示されたURLの `/` を開く。
2. ホームの非言語から01へ。回答前は選び直し、回答後は変更不可を確認。
3. 解説を閉じて再表示。手書きと文字メモを保存し、再読み込みして同じ問題・選択肢順・回答・メモから再開することを確認。
4. 10問完走して「結果を見る」→「次へ」。低得点でも02が現れることを確認。
5. 05の後はCHECK、その後は06。「これまで」で過去を展開。
6. 6点以下で復習へ。新しい10問を解き、7点以上なら対象から外れることを確認。
7. 狭い画面でも固定解説の次問ボタンが表示され、長い解説は本文のみスクロールできることを確認。

検証結果: ビルド・型チェック・コード検査・自動テスト36件が成功。ブラウザーで通常01〜05とCHECKの完走、06の解放、問題/解説/メモの再開、復習8点での解除、390px幅の固定解説を確認。全問題の内容を人手で精査したものではありません。

## 残る範囲・注意点

言語の本番問題とEXTRAは未実装（言語は準備中）。図・画像を含む問題の契約も未対応です。現状はテキストと表を扱います。

保存はブラウザーの端末内のみ。アカウント同期、複数タブの同時編集の競合解決、履歴の容量整理は未対応。同じアプリは1タブで使用してください。保存失敗時は警告と再試行を表示します。旧履歴は取り込みますが、旧分野MAPの成績を番号付きステージの完走には変換しません。

問題の種類が少ない場合は直近問題の回避条件を緩和しますが、同一セット内は重複させません。条件に合う10問を生成できない場合は元の回答済み状態を保ったまま再試行できます。
